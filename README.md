# My Profile

A personal profile page built as a single HTML file (`index.html`) with HTML, CSS and JavaScript in one place and no external dependencies.

**Live site:** https://my-profile-lyart-rho.vercel.app/
**Author:** Aswira Haider 

## Features

- Responsive layout that works on desktop and mobile
- Light and dark mode with a toggle button
- Sections for About, Skills, Projects, Education and Contact

## AI tool used

This page was created with **Claude** (by Anthropic).

### Prompt

> Create a single-file, responsive HTML profile page (HTML, CSS and JS in one index.html). Include: name, photo placeholder, short bio, skills, projects, education, and contact links. Use a modern design with dark/light mode. No external dependencies.

I then replaced the placeholder text and photo with my own details.

## Files

- `index.html` : the complete profile page
- `photo.jpg` : my profile photo
- `README.md` : this file

## How it was deployed

1. Created the page with an AI agent.
2. Uploaded the project to this GitHub repository.
3. Deployed it from GitHub on Vercel. Every push to the repository redeploys the site automatically.
